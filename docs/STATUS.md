## Decisions and deviations from the plan

- 2026-10-30. The `Data` package is named `DataLayer` (name clash with `Foundation.Data`).
- 2026-10-30. The project is generated by XcodeGen; `.xcodeproj` is not in git, to enable parallel work.
- 2026-10-30. Xcode 16.1 locally: Liquid Glass behind `#if compiler(>=6.2)`. Waiting for Xcode 26
  and an iOS 26 simulator to verify.
- 2026-10-30. `PlaybackSnapshot` has no current time; progress is polled via `currentTime`.
- 2026-10-30. Bundle ID `com.starodub.SeryaPlayer`, App Group `group.com.starodub.SeryaPlayer`.
- 2026-10-30. The browser is enabled via the `SP_BROWSER_ENABLED` flag in both configurations.
- 2026-10-30. All repository content is in English; UI strings are English in code with a Russian
  translation in the String Catalog (the plan originally had Russian as the primary language).
- 2026-10-30. The repository is public (free GitHub Actions on macOS). Commits use the GitHub noreply address.
- 2026-10-30. Workstreams run on Sonnet by default, one or two at a time; sessions skip simulator
  screenshots (the orchestrator checks visuals after wiring) and don't wait for CI.
- 2026-10-30. `PlaybackControlling.jump(toQueueIndex:)` added (player).

## Open questions

- Known edge cases to revisit: with a track queued twice, turning shuffle off picks the first
  occurrence; deleting tracks leaves gaps in playlist `sortIndex` (order stays correct).
- Toolchain drift: CI runs Xcode 16.4 and the latest SwiftFormat; local is Xcode 16.1 and SwiftFormat 0.64.4.
  CI is the reference — run `brew upgrade swiftformat` locally.

- Whether to exclude `Media/` from iCloud backup (large libraries).
- Xcode 26: once installed, verify the build and add iOS 26 to CI.

## Decisions and deviations from the plan

- 2026-10-30. The `Data` package is named `DataLayer` (name clash with `Foundation.Data`).
- 2026-10-30. The project is generated by XcodeGen; `.xcodeproj` is not in git, to enable parallel work.
- 2026-10-30. Xcode 16.1 locally: Liquid Glass behind `#if compiler(>=6.2)`. Waiting for Xcode 26
  and an iOS 26 simulator to verify.
- 2026-10-30. `PlaybackSnapshot` has no current time; progress is polled via `currentTime`.
- 2026-10-30. Bundle ID `com.starodub.SeryaPlayer`, App Group `group.com.starodub.SeryaPlayer`.
- 2026-10-30. The browser is enabled via the `SP_BROWSER_ENABLED` flag in both configurations.
- 2026-10-30. All repository content is in English; UI strings are English in code with a Russian
  translation in the String Catalog (the plan originally had Russian as the primary language).
- 2026-10-30. The repository is public (free GitHub Actions on macOS). Commits use the GitHub noreply address.
- 2026-10-30. Workstreams run on Sonnet by default, one or two at a time; sessions skip simulator
  screenshots (the orchestrator checks visuals after wiring) and don't wait for CI.
- 2026-10-30. `PlaybackControlling.jump(toQueueIndex:)` added (player).
- 2026-11-01. Device feedback round (#13). Domain changes: `PlaybackControlling` is `Sendable` and gains
  `removeFromQueue(trackIDs:)` (delete use cases call it); `ImportProgressCenter` and batched import writes;
  `StartPlaybackUseCase.playOrToggle`.
- 2026-11-01. Equalizer is one sheet at `.fraction(0.9)` laid out like Settings (replaces the `.medium`/`.large` plan).
- 2026-11-01. Library home is a `ScrollView`, not a `List`: a List cell owns one context menu for the whole row,
  so shelf cards couldn't have their own.
- 2026-11-01. Never give `swipeActions` buttons `role: .destructive` when deletion is confirmed: SwiftUI removes
  the row before the confirmation and the real delete then crashes the list. Use `.tint(.red)`.
- 2026-11-01. List rows read the playing track themselves (`playback:` store passed to the row), never the list
  body: otherwise every playback change re-renders and re-diffs every row (visible stutter in Debug builds).
- 2026-11-01. Audio stutter and UI hangs seen on device happen only under the Xcode debugger; judge
  performance from a build launched from the Home Screen.
- 2026-11-01. Signing lives in the git-ignored `Configs/Local.xcconfig` (included by `Configs/Base.xcconfig`).
  `scripts/test.sh` runs `xcodegen --use-cache`, so it no longer rewrites the project under an open Xcode.
- 2026-11-01. String Catalogs are kept in Xcode's exact format with `scripts/format-xcstrings.swift`;
  preview-only strings are marked Don't Translate.
- 2026-11-01. "Allow auto-merge" is on, but `main` has no required status checks (the ruleset only blocks
  force-push and deletion), so PRs are merged by hand after CI is green.
- 2026-11-01. Scope cut for wave 3 (user decision): no in-app browser and no download by link; the Browser tab
  becomes a Settings tab (Settings leave the Library toolbar); `BrowserFeature` and the browser flag are removed.
  "Share to SeryaPlayer" already works through the app's audio document types (checked on device), so no Share
  Extension. Smart playlists and gapless playback are dropped from `extras` (gapless rewrites the engine's
  scheduling, which works on device; revisit only if gaps bother the user). `extras` is split into sessions,
  at most two at a time: step 1 `settings-tab` + `sleep-timer`; step 2 `visualizer` + `rate`.
- 2026-11-02. Sleep timer (#16). Domain changes: `SleepTimerControlling` + `SleepTimerState`
  (`off`, `countdown(deadline:)`, `paused(remaining:)`, `endOfTrack`) + `SleepTimerOption`; `PlaybackEngine.setVolume`.
  The countdown runs only while music plays (user decision); the last 10 s fade on the main mixer; "End of Track"
  advances to the next item and leaves it paused, like Apple Music. The active button shows the remaining time on the
  highlight, like Podcasts.
- 2026-11-02. Rate and position memory (#17). Domain changes: `PlaybackRate.options` (0.5–2×), global
  `AppSettings.playbackRate`, `TrackPositionRepository` (UserDefaults implementation), `NowPlayingInfo.defaultRate`.
  Positions are kept only for tracks of 20 min or longer, dropped under 10 s or within the last 30 s.
  `AppSettings` decodes every key with `decodeIfPresent`, so new settings never reset old ones.
- 2026-11-02. Visualizer (#18). Domain changes: `AudioSpectrumProviding`, `AppSettings.showsVisualizer`. A tap on the
  main mixer feeds vDSP; bars are drawn with Core Animation (a SwiftUI Canvas cost ~26% CPU on device) and
  normalised by `AutoGain`. Tapping the artwork toggles it; the choice is remembered.
- 2026-11-02. List rows show 4 live white spectrum bars on the dimmed artwork instead of the `waveform` symbol (#19);
  bars fall to the full player's rest state on pause. `SpectrumBars` moved to DesignSystem; Library/Folders
  dependencies gained `audioSpectrum`. Simulator CPU with the playing row visible: ~7.7% → ~2.6%.
- 2026-11-02. Back button is fully native (system label), hidden while selecting (Files/Photos pattern) (#20).
  Hiding the label (`.toolbarRole(.editor)`, `backButtonDisplayMode = .minimal`, empty title) makes the chevron dip
  on pushes from large-title screens on iOS 18; a transparent title works but shifts leading items — rejected by
  the user. Selected rows keep the system highlight.
- 2026-11-02. The app is iPhone only, set on the app target (`TARGETED_DEVICE_FAMILY`, no Mac/Catalyst/Vision):
  XcodeGen's iOS app defaults override project-level settings.
- 2026-11-02. Pause/resume (#21): pause fades out over 80 ms on a fader mixer after the player, then pauses the node
  and the engine; resume fades in. No reschedule on resume. TimePitch is out of the chain at 1× (it added ~85 ms of
  latency). The engine must not keep running while paused: iOS infers Control Center's play state from audio output.
- 2026-11-03. iOS 26: the tab bar does not minimize on scroll (no `tabBarMinimizeBehavior` in `RootView`), by the
  user's choice. `adaptiveTabBarMinimize()` and the inline mini player artwork size are ready if that changes.
- 2026-11-05. iOS 26 decisions (PR #22): Folders keeps the stock plain list with pinned section headers and no
  header background, as on iOS 18 (the user tried grouped, row-coloured and header-background variants and chose
  stock). Never use `scrollEdgeEffectStyle(.hard)`: it leaves background tabs in the old theme. Left as iOS 26
  system behaviour: the cross-fade on tab switches. (The opaque flash on the zoom dismiss was ours, fixed in #26.)
  The full player swipe-dismiss from the sliders (PR #24) was rejected after a device check.
- 2026-11-06. iOS 26 mini player (#26): the full-screen cover's default opaque presentation background stayed
  clipped to the accessory for ~1 s after a swipe-dismiss; it is `.clear` on iOS 26 (the player draws its own).
  Tracks without artwork: graphite full player background (not Serya Blue), a stronger placeholder tile there;
  the Lock Screen cover is rendered from DesignSystem's `NoArtworkCover`, so the two can't drift. An opaque grey
  placeholder everywhere was tried and rejected (too heavy).
- 2026-11-06. The orchestrator doesn't write code; even `App/` and `project.yml` changes go to a session whose brief
  allows them. A "system bug" claim is proven the way the user agrees to, not with a separate sample app by default.

## Open questions

- Known edge cases to revisit: with a track queued twice, turning shuffle off picks the first
  occurrence; deleting tracks leaves gaps in playlist `sortIndex` (order stays correct).
- Toolchain drift: CI builds with Xcode 26.3 (lint on the image default) and the latest SwiftFormat; local is Xcode 26.3
  (16.1 kept) and SwiftFormat 0.64.4. Local SwiftLint 0.53 crashes under Xcode 26.3: lint with `DEVELOPER_DIR` = Xcode 16.1.
  CI is the reference — run `brew upgrade swiftformat` locally.

- Whether to exclude `Media/` from iCloud backup (large libraries).
- A rate change from a remote command (Control Center, headphones) isn't persisted to settings (minor).
- Xcode 26.3 is the newest Xcode this Mac (macOS 15.7.5) can run; 26.4+ needs Tahoe 26.2.
- Library perf tests (`groupsTenThousandTracks`, `handlesTenThousandTracksWithFastSearch`) use wall-clock limits
  that slow CI runners occasionally miss on the iOS 26 job; loosen them if they start failing often.
